Three AI-powered tools

The Platform — Open to Every Researcher

Built on real preclinical data from 84 animals and validated against Saigon cinnamon. Input any African plant. No coding required. No account needed. Download once, run anywhere.

MODULE 01
🔬
Plant → Drug Screener
Enter any plant or compound. Get binding affinities, ADMET profile, network targets, and a translational drug assessment — in under 60 seconds.
  • Predicted binding affinity against 8 neurodegeneration targets (AChE, BACE1, NF-κB, NRF2, COX-2, GSK3B, CASP3, MAPK1)
  • Full Lipinski drug-likeness and ADMET toxicity scorecard
  • Network pharmacology map — hub targets and disease pathways
  • Lead grade (A/B/C), collaboration need, and AI narrative for co-authors
  • Benchmarked against Cinnamaldehyde reference data from real study
Open Module 01 →
MODULE 02
🧬
Virtual Preclinical Cohort
Replace or refine animal experiments. Generate a complete synthetic preclinical cohort with predicted biomarker trajectories — built on a validated Gaussian copula engine.
  • Correlation-preserving synthetic data — r = 0.37 corr-of-corrs fidelity vs 0.01 for independent baseline
  • Predicted biomarker trajectories per treatment group as SVG charts
  • ML classification accuracy estimates benchmarked against 84.8% LDA result
  • Statistical power analysis and recommended cohort size per endpoint
  • NC3R ethical statement (Replace · Reduce · Refine) for ethics committees
Open Module 02 →
MODULE 03
🤖
Human Trial Simulator
The bridge no one else has built. Predict what happens in a human patient before the first clinical dose — allometric scaling, Phase I/II simulation, West African pharmacogenomics.
  • Allometric dose scaling from rat to human (FDA methodology)
  • Phase I safety simulation — dose escalation, predicted adverse events
  • Phase II efficacy prediction — effect size, sample size, endpoints, success probability
  • West African population considerations — CYP2D6, APOE4, dietary interactions
  • IND readiness score (0–100) + NAFDAC / EMA regulatory pathway map
